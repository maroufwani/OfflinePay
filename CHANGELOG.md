# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0-beta] - 2026-04-10

### Added

- Send money via mobile number
- Send money via UPI ID (payee address)
- Request money
- Check account balance via USSD
- QR code scanning for payments
- Transaction history with details
- Favorite recipients management
- Biometric app lock
- Dark, Light, and System theme support
- Dual SIM support
- On-device encryption (SQLCipher + EncryptedSharedPreferences)
- Onboarding flow for first-time setup
- Receipt sharing
- Input validation for phone numbers, UPI IDs, and amounts
- Accessibility Service for USSD dialog automation (scoped to `com.android.phone`)
- Overlay-based PIN/input entry during USSD flows
- Privacy Policy, Terms of Service, and Disclaimer documents
