## 2. Description of the App

Offline Pay is an open-source Android application licensed under the Apache License, Version 2.0. The App provides a user interface to interact with the `*99#` USSD-based payment service operated by the National Payments Corporation of India (NPCI).

The App:
- Dials USSD codes (`*99#`) using your device's telephony capabilities
- Uses an Accessibility Service to navigate USSD menu dialogs
- Stores all data locally on your device
- Does **not** process, store, or route any payment or financial transaction on any server
